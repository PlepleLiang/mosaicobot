## 创作、应用中心与设备 Works

手机负责理解意图、保存作品及版本，用户确认后才部署。生成完成、保存、上传、发布、启动、运行和画面验收是不同状态，不能用状态标签证明真实硬件运行。

应用中心的获取会创建本地作品副本，不自动部署。上传只是本地列表模拟，需确认权利和隐私；没有公共后端。删除上传不会删除已经获取的副本。设备系统保留 11 个系统入口及 3 个预装 Works，个人作品由 Works 独立管理。

原型可检查模拟连接、断线与恢复、生成重试、版本与修改、设备部署、Works 删除，以及获取 / 上传。它与参赛展示站的浏览器作品列表互不同步。

## 通用横屏手柄

手机提供标准按钮与双轴，Mosaico 独立显示运行，不是手机投屏。进入手柄不应自动获取、部署或停止作品。Start / Select 是游戏输入，不是系统菜单。

评审选择器可切换未连接、就绪、等待游戏、不支持、被占用、断线、后台恢复、设备重启等模拟状态。旋转、失焦、后台和菜单释放输入；恢复前需重新检查状态，不抢占控制权。竖屏显示旋转提示。

本次发布保留仓库版本的通用输入观察台。新展示站另有可玩的游戏演示，两者不是同一状态或引擎。

## 硬件系统与形态边界

硬件系统页展示主屏、消息、应用、控件、更多、充电、息屏、插入与 Works 等页面设计。页面是可操作设计稿，不是设备验收证据。

手机背贴、掌机联屏和手机 / 背包挂件是参赛形态概念。本站不承诺附件量产、磁吸规格、真实模型响应时间或任意应用生成。真实 Android 与设备能力以源码和实际设备验收为准；本项目当前局域网设备接口不适合暴露公网。
