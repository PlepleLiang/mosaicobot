支持哪些输入与修改？

仅支持贪食蛇、坦克、飞机、赛车、像素宠、光点画板、专注、签名、表情（也支持场景英文名）。可加橙色 / 绿色 / 蓝色 / 粉色，慢速 / 中速 / 快速，专注 1–60 分钟。签名文字在下方编辑。其他需求明确不支持；不模拟任意应用生成。

本地模板匹配，不调用 AI、不执行 Lua、不请求网络。画面与设备实现不保证一致。
