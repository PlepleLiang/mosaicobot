## 这次改什么

把设备系统界面统一为「石墨仪表」：近黑底、暖白数字、线性图标、克制的信号橙。信息按时间 / 功能 / 状态排列，不用装饰面板挤占屏幕。保留原有应用、下拉栏和返回习惯。

当前可视源文件是 index.html、design.css、design.js；画廊与主预览使用同一套画面函数，避免静态图与交互稿各画一套。所有状态为本地演示，页面没有外部请求、设备接口、模型调用或持久化写入。

## 操作方式

- 左侧切换九个画面；屏外按钮是评审操作，不是新增硬件按键。
- Hub 左右滑动或点击页码切换；顶部下拉控制栏；上滑或点击底部箭头收起。
- 原应用入口可点击。Works 保留四行、标签和分页，运行行点击停止，已停止行点击打开。返回恢复 Works 标签与分页，不因返回而停止作品。
- 音量 / 亮度可以拖动，也支持键盘方向键。Esc 返回，按钮均有可见焦点。
- 右侧可切换天气 / Agent 配置 / 模块示例，以及 Works 的启动中、运行中、停止中、已停止、失败、空态和分页；通知可切换空态。
- 截图总览固定展示默认示例，不随交互预览的状态修改，便于对照评审。

## 不虚构的状态

1. Join、Bluetooth、Low power、Ringtone 当前只会反馈 Not Supported。设计仍保留这四个入口，使用 RESERVED / 虚线呈现；它们不是可开关的功能。
2. Wi-Fi 和 Vibration 对应原可用切换逻辑。原型只做本地演示；真实实现必须沿用原错误反馈 / 回滚。
3. 控制栏音乐整块是打开 Music 的入口，不是暂停、上一首、下一首播放器。
4. Agent 的 CFG 仅代表 LLM 和至少一个 IM 通道已配置；不表示手机已连接、Agent 在线或模型调用成功。
5. 通知数据来自现有场景的示例结构，不宣称已经接入实时历史服务；空态是显示设计。评审通过屏外入口进入通知页，不擅自添加尚未核实的通知手势或新铃铛入口。
6. 控制栏保留在现有 Hub / 锁屏作用域内，不承诺覆盖到所有应用。
7. Weather unavailable、空模块槽位有明确文本。时间、电量、相机插入等值均为设计示例。

## 视觉规格

| Token | 值 | 角色 |
| --- | --- | --- |
| Screen | #101416 | 系统画布 |
| Panel | #1C2226 | 应用与控制面板 |
| Text | #F1F2E9 | 主文字 |
| Secondary | #A6B0B5 | 次文字 |
| Signal | #FF753E | CLAW、已开启控制、充电 |
| Running | #B5D59E | 已运行状态，同时有文字与停止图标 |
| Error | #FF9A86 | 错误文字 / 图标 |
| Rule | #485257 | 分组线；不单独承担控制识别 |

固定 480×480 **逻辑像素**，不是 Android dp。外框四边等宽、内屏圆角约 10%，不改成圆屏、不加底座。画面在浏览器内等比缩放，不重新排版成手机布局。主信息左右留白 24–28；应用间距 10；卡片圆角 12–20。常规应用名称 17–18，标题 27–29，首页时间 112；辅助等宽标签 11–16。辅助字号与触控物理尺寸须在 GSP_SIM 和实机确认后再定稿。

网页采用本机 Segoe UI / Microsoft YaHei 与 Consolas，不依赖在线字体。图标为统一 24 单位、1.65 描边的内联矢量，不使用 emoji。后续嵌入式字体需使用现有字体或离线字形资源，不能假定设备具备网页字体。

不使用玻璃模糊、全屏粒子、持续波形动画或渐变背景。锁屏更暗是视觉选择，不作为省电效果声明。

使用用户指定的 ui-ux-pro-max（实际路径 C:/Users/admin/.cursor/skills/ui-ux-pro-max/SKILL.md）。执行设计系统检索：首轮 embedded hardware dark instrument 返回音乐类结果，不采用；收窄 dark industrial dashboard minimal 后，只采纳适合嵌入式的深色高对比、层级与状态原则，不采用玻璃模糊或营销页结构，不持久化不匹配的完整结果。

针对 dragging movements 的检索用于补充手势的点击 / 键盘替代；html-tailwind 检索只采用语义按钮、标签和响应式通用建议，本地原型没有引入 Tailwind。当前配色、网格与硬件映射是结合工程约束的设计判断。
