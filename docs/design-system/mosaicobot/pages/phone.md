## 视觉基准

以用户提供的「设计稿.png」为准。保留暖白、轻边框、细线图标、浅色图标底块与内容区留白。不是重新设计成高密度聊天工具，也不是修改系统字体大小。

默认字号下，Android 使用 dp/sp、HTML 使用同值逻辑 px：

- 顶部 73 高，左右 21；字标 21/27、副标题 10/14，48×48 新建按钮。
- 连接卡最小 62 高、左右 17、底部留 8；36 图标底块、12/17 标题和 10/14 说明。
- 正文左右 21；欢迎标题 28/40、说明 12/22；两张最小 62 高的灵感卡，间距 7。
- 输入框左右 15、圆角 17、内边距左右 12 / 上下 10。提示语 10/16 → 输入 14/22 → Agent 标签和 48×48 发送按钮；默认约 140 高，保留三段式结构。
- 输入框下方标语 9/14，上下 7/8。导航 4 顶部间距 + 最小 55 高点击区域，21 线性图标、28 选中底块、10/16 标签。
- 系统安全区另计一次。不能压缩真实状态栏/手势区，也不能通过改 wm density 或 font_scale 假装比例正确。大字体允许控件自然增长。

## 创作

主导航：创作 / 应用 / 设备。切换手机页面不改变设备运行。设备页没有重复的顶部连接胶囊。

空态只显示欢迎、两个灵感入口和自然语言输入。灵感及修改建议仅填入草稿，由用户发送；不自动调用模型。当前只接入屏幕/触摸生成，无语音输入入口。

输入固定、正文独立滚动。输入至少 56 高、最多显示三行，超出后在输入框内滚动。空输入与忙碌状态真实禁用发送。发送后收起键盘，不修改模型及运行授权逻辑。

键盘打开时隐藏连接卡、导航与标语，输入保持在 IME 上方；键盘关闭恢复参考布局。错误属于正文流，可关闭且新错误自动滚入可见区域，不做一直占高的固定横幅。

作品卡：运行状态 → 76 图标 + 名称/版本/能力 → 运行与详情按钮 → 修改建议 → 回执时间/保存状态。Lua 图标不是硬件首帧。源码和 SHA-256 在详情中展示。
