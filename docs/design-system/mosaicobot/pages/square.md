# Mosaico · 运行主体 / 系统视觉 06

2026-10-13。手机规则仍继承 MASTER 05；本文件覆盖设备系统外观，以 [硬件可交互设计稿](../../../hardware-redesign/index.html) 与 [详细设计边界](../../../hardware-redesign/README.md) 为准。**用户已确认并授权实现、构建与刷写；设备系统场景和显示绑定已更新。**

## 实体与画布

完整圆角方屏，480×480 逻辑像素。浅色等宽外框、内屏圆角约 10%；无底座、无底部加宽、无圆形裁切。桌面和窄屏评审均保持方屏内容等比缩放，不把设备布局改成手机响应式界面，也不把逻辑 px 当作 Android dp。

## 视觉覆盖规则

- 底色 #101416，面板 #1C2226，暖白文字 #F1F2E9，次文字 #A6B0B5，信号橙 #FF753E。
- 统一矢量线性图标；不使用 emoji、玻璃模糊、大面积渐变或持续装饰动画。
- 状态栏 Wi-Fi 固件显示框为 24×24，在原 40×40 槽位内居中（内偏移 8,8），首页与下拉栏一致；保留五档信号状态，下拉栏 Wi-Fi 开关尺寸不变。
- 主屏数字时间为主信息，天气为一行辅助信息；Camera / CLAW / Works 在下方，CLAW 单点强调。
- 主页数字时钟替换现有模拟表盘，需要少量时间文字绑定调整，不声称只是换一张图。
- 主屏第一应用页保留 Settings / IMU / Album / Music / Bricks / Weather；第二应用页保留 Interaction / Partner。
- Works 保留 Recent / Installed、每页四行、分页与原启停行为；Dino / Flappy Bird / Works Album 与用户作品继续共存，Works Album 与系统 Album 不合并。
- 下拉栏重绘为连接、Music 入口、左右模块、音量与亮度四个区域；保留六个 72×72 触点和两根 72×152 滑杆原坐标。
- Join / Bluetooth / Low power / Ringtone 明示 RESERVED，点击仍仅反馈 Not Supported；不新增可用能力。
- 通知页保留滚动和返回，提供静态样例与空态，不新增通知后台、清空操作或未核实的全局通知手势。
- AOD / 充电 / 模块插入共享相同字体、图标、层级，复用现有数据与生命周期。

所有时间、电量、天气、Agent 配置、作品运行与模块连接状态均为原型示例，不是遥测。Agent configured 不等于手机在线或模型调用成功。下拉栏保持现有 Hub / 锁屏作用域，不承诺覆盖所有应用。

## 交互与实现边界

硬件触摸是主要输入。原型屏外导航、场景切换和状态切换只供评审；手势同时有点击 / 键盘替代。点击原有应用展示边界占位，不假装这些应用已经被本轮重新实现或部署。

生成作品继续归属 Works / 我的创作，不擅自修改静态 Hub 网格。返回 Works 恢复原标签 / 分页，不自动停止作品。真实启停错误、等待和回滚仍由既有运行时处理；网页示例不代表实时行为。

本设计不引入「配对号码确认」能力；当前连接方案按 interaction.md 的局域网发现与接口检查处理。不要从旧版方屏规则推断存在安全配对、设备权限隔离或未实现的控制开关。

## 与主设计稿的关系

docs/mosaicobot/index.html 直接嵌入九屏可交互系统设计，右侧 Canvas 同步石墨底色、数字时钟和应用卡片布局。原有应用、贪食蛇和生成 / 返回交互保留；各原应用内部画面不在本轮重做范围。hardware-redesign/index.html 是同源组件和独立全屏入口，不再要求离开主稿查看新版。

手机断连不表示设备停止。原交互模拟中的独立运行、冻结最后回执与作品确认规则保留。Vibe 原生游戏的构建 / 固件切换与 Claw Works 运行时作品不是同一安装路径，不因视觉统一而混用。
