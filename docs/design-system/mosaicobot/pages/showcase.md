## 呈现与交互

首屏保留手机背贴、掌机联屏、独立挂件三种实体构图。创作台右栏上方增加同样可切换的独立草稿试玩，作品列表在其下；两处 Screen、形态和输入互不串扰。两处掌机均采用方屏在上、横屏手机手柄在下，至少留 16px 间距，无遮挡。背包与手机挂点可切换；外观是概念，不声明磁吸与量产。

创作台支持九种模板与有限参数；未知意图拒绝，不假装任意 AI 生成。默认可用，移除模拟连接状态、计时器和部署门槛。生成或有效参数编辑 → 立即运行草稿试玩 → 保存不可变版本 → 用户确认部署 → 上方方屏运行 → 新版本修改。保存、打开、修改也更新试玩；放弃后展示明确空状态。试玩不等于已保存或部署，确认前上方旧版本不受影响。站点、本机 App 和旧原型数据互不同步。

沿用 `interactive preview immediate feedback --domain ux` 的即时反馈与输入可供性建议；不添加框架。主要按钮深底白字；选中悬停保持深底。控件至少 44px，方向键触点 44px；状态有文本，像素宠数值与反馈提供文字替代。两处均支持运行生命周期、触屏 / 键盘与画板交互；聚焦哪处只控制哪处。模态打开或取消不暂停方屏，但清零输入；确认部署后保持创作区可见，焦点进入草稿方屏。后台 / 失焦清零并暂停两处；形态 / 编辑焦点切换释放输入；短按开火使用输入边沿。

布局覆盖 320 / 375 / 768 / 1024 / 1440。小屏创作区上下堆叠；减少动态效果设置禁用装饰动画，草稿生成与有效修改立即启动功能预览，用户随时可暂停。原交互链接保留完整评审场景。
