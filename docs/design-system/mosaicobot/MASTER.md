## 设计命题

**手机是随身工坊，Mosaico 是可编程的身体。**

普通用户的第一问题是“我想让它做什么”，不是“应该打开哪个应用 / 连接哪个端口”。设计围绕一个连续创作会话：意图、生成、运行、反馈、再修改。

视觉方向：温暖、克制、有实体感的工具界面。暖白手机与深色硬件屏幕形成角色区分，保留 Mosaico 的橙色辨识。让作品成为重点，不画调试 IDE，也不做充满功能卡片的设备管理后台。

## 排版与节奏

字体使用系统 Segoe UI / PingFang SC / Microsoft YaHei，标识与技术辅助文字使用系统等宽字体。不依赖在线字体服务。

- 评审页标题 43px，窄屏 31–34px；分区标题 23–26px。
- 手机欢迎标题 28/40；会话正文和输入 14/22；欢迎说明 12/22；作品标题 17/24。字号/行高必须成对声明，避免小字号继承 24sp 行高。
- 10–12px 用于评审模型中的辅助标签；设备 Canvas 主要文字按 480px 逻辑尺寸绘制。
- 4/8px 节奏为基础，模块留白 16/24/32px；不同角色间保留明显空白。
- 手机操作目标至少 48px，图标视觉通常 18–22px。
- 原生实现应适配平台字体缩放与安全区，不把 HTML 设备外框当成真实 App 的固定屏幕尺寸。
- 2026-10-13 以用户指定截图为基准：顶部 73、连接卡 62、三段式输入约 140、导航约 60（不含系统栏），详见 phone.md。未采用将发送按钮搬到输入文字右侧的临时方案。
- 图标与 HTML 共用形状语义及 1.65/24 描边比例；Android WorkshopIcons 对应原稿 SVG，不使用实心网格代替线框四宫格。

## 形状与层次

手机硬件外壳约 43px 圆角，内部画布 35px；应用卡片 12–17px，弹窗 25px。边框轻，投影主要服务于实体设备，不给每个 App 卡片加大阴影。

Mosaico 保持正方形、四边等厚浅色边框，逻辑画面 480×480、内屏圆角约边长 10%。设备边框中的轻微明暗用于模拟材质，不采用大面积装饰渐变。无底托、无下巴文字、无圆形裁切。

图标为统一描边的内联 SVG，优先遵循 Phosphor 式简洁线性语义；无需运行时图标库。四个方块的字标是概念原型标记，不宣称为 Espressif 官方商标。

## 交互原则

1. 创作页只出现一个主要输入动作，不要求先选择技术模式。
2. 等待有阶段，异常有下一步。上传、运行、健康是不同语义。
3. 同一任务不得被第二次发送无声覆盖；切换作品前需完成或取消当前任务。
4. 断线保留对话与作品；手机显示缓存状态，设备继续自身运行。
5. 所有成功状态明确来自模拟或真实回执。原型全程显式标注模拟。
6. 当前每个版本确认后运行；全局自动运行不可用，敏感硬件不在手机生成范围。
7. 主导航仅“创作 / 应用 / 设备”；应用内分「我的创作 / 应用中心 / 设备应用」（07 应用中心提案待确认）。设计稿评审按钮不进入产品导航。
8. 点击有反馈、disabled 有真实禁用属性、输入有可见标签、删除有确认。
9. 原生 dialog 管理焦点范围；Escape / 关闭 / 取消有一致行为，退出后返回触发控件。
10. 尊重 reduced-motion。过程状态不依赖 CSS 动画结束；游戏运动是用户主动触发的功能内容，可暂停。

11. 保留原有时钟 / 天气首页、两页 Claw 应用和 Works 预装作品。设备应用详情是预览，明确打开后才切换前台。
12. 同时区分系统 Album 与 Works 的 album_app；生成作品不覆盖系统入口。
13. 停止自创作品返回时钟首页，从 Works 启动的应用可返回原 Works 分页。离线手机只显示最后回执。

- “断连返回首次引导”。
- “手机画面永远与硬件完全一样”。
