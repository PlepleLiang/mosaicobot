# MosaicoBot Android · 0.1 开发预览

原生 Kotlin / Jetpack Compose 手机端，不是 HTML 包壳。手机 Agent 负责生成作品，Mosaico 是独立运行主体。

当前实现 **真实生成 → 本地检查 → 版本保存 → 文件读回校验 → Works 发布 → 显式启动/停止 → 任务状态查询**。新固件需支持 /api/works；每个版本确认后运行，尚未提供安全沙箱或全局自动运行。running 是任务状态，不是首帧/交互验收。

## 快速开始

要求：JDK 17 或 21、Android SDK 36、Android 11/API 30 以上设备。项目带 Gradle Wrapper。

在 PowerShell 中执行：

~~~powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-21.0.10'
$env:ANDROID_HOME='D:\Android\Sdk'
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug --console=plain
& "$env:ANDROID_HOME\platform-tools\adb.exe" devices -l
& "$env:ANDROID_HOME\platform-tools\adb.exe" -s <设备序列号> install -r app\build\outputs\apk\debug\app-debug.apk
~~~

构建产物：app/build/outputs/apk/debug/app-debug.apk，包名 dev.mosaicobot。
若出现 INSTALL_FAILED_USER_RESTRICTED，请在手机上允许本次安装/检查开发者选项的 USB 安装开关。不要绕过系统限制。

打开「设备 → 模型与接口设置」，填写自己的 Key。默认配置：

- Base URL：https://models-proxy.stepfun-inc.com/v1（参考本机 StepGo/StepCode）
- 模型：step-5-preview:stepfun
- 协议：POST /chat/completions，非流式请求

可在设备页点击“测试模型连接”，发送一个最小请求检查 Key、接口与网络。代码生成每次请求使用 16384 token 输出预算，读取上限 300 秒、单次总时限 360 秒。整个生成任务最多 8 次模型请求、总时限 12 分钟，可随时取消。真实贪食蛇首测约 3 分钟，自动续写可能增加耗时和模型用量。

2026-10-12 验证：本次提供的 Key 可以调用上述文本模型，但不能调用 PC Codex 默认的 gpt-6-astra（403）。不借用 PC 其他账户凭据。Key 不打包到 APK，不记录到日志，由 Android Keystore AES-GCM 加密保存；卸载后需重新配置。

## 使用流程

1. 「创作」选择“生成贪食蛇”或输入意图，点击发送。无需先连接硬件即可生成。
2. Agent 遇到输出截断时自动续写并精确拼接，每个候选包最多续写 3 次；校验不通过或续写耗尽时最多完整重写 2 次，仍受总计 8 次请求限制。每轮保留完整需求及旧版本源码，要求保留功能。默认输出带标题/说明与结束标记的原始 Lua 应用包，兼容旧 JSON 格式；只有唯一完整的应用包通过 Lua 语法与能力 lint 后才返回作品，手机不执行生成代码。失败或取消保留原需求和已有版本。
3. 成功后自动保存作品和版本；查看源码、继续修改或在「应用」中重新打开。删除只影响手机上的该版本。
4. 手机和 Mosaico 接入同一可信局域网，打开 App 即自动扫描并连接。可在「设备」手动扫描、停止扫描、切换已发现设备，或展开手填地址入口。连接前会读取并验证 Claw 状态与模块列表。
5. 查看源码并明确确认后，检查设备已有版本。同版本已部署时只读回核对源码与清单，不重复上传；已注册到 Works 的版本不重复发布。新版本才传输至 DATA/apps/独立版本目录，逐文件读回校验 SHA-256，launcher.json 最后上传。
6. 确认运行也包含切换手机作品：查询设备 DATA 目录中的手机生成作品，先停止正在运行/启动的旧作品，等待停止完成再 start 目标版本。系统和预装作品不自动停止。目标已 running 时不重发任何写请求，已 queued 时只等待。查询到 running 才显示运行；停止失败、超时或状态不明时中止切换。后台/断线不自动停止设备，写请求不自动重试。

屏幕文字受设备内置字体限制为 ASCII；手机标题和说明支持中文。生成能力包含屏幕/触摸、设备真实时钟和受限 HTTPS 数据读取。相机、录音、音频、网络写入/鉴权密钥、文件或执行器的需求不应被悄悄降级，应返回不支持的说明。

## 自由创作游戏：默认触屏 + 手机手柄

直接说“生成贪食蛇”或描述游戏玩法，不必再额外要求手柄支持。Agent 的生成与编辑规则默认要求：

- Mosaico 单独用触屏即可开始、完成核心操作、暂停/继续、重试和 EXIT；不以手柄连接或 Wi-Fi 为启动条件。
- 手机方向键/左摇杆、A、Start 等标准输入与触屏驱动同一份游戏状态；按玩法处理长按、边沿与摇杆幅度，不重复触发动作。
- 初始无手柄正常运行；区分 connected 会话与 input_active 输入时效。350ms 短超时清零并临时冻结/提示信号弱，可触屏接管，不设正式暂停；真正失联才暂停一次。恢复新鲜输入不解除手动暂停，重连不重开游戏。
- 仅在用户明确要求“只用触屏，不要手柄”时生成仅触屏游戏；时钟、天气等非游戏不强行加入手柄。

源码首行由模型声明 `-- interaction: game-dual` / `game-touch` / `app`。只在 Agent 生成/修改返回前执行结构检查：触摸读取、EXIT 字符串、gamepad 生命周期、会话连接/输入时效与按键输入引用；忽略注释或字符串内的伪调用。遗漏会进入已有完整修复流程，包括续写返回的完整替代包；完整代码缺少操作能力不按截断继续追加。

分类依赖模型遵守需求；结构检查不证明代码可达、触屏热区有效或玩法完整，也不保证每次生成成功。沿用有界重试，失败不覆盖已有作品。旧作品的读取、导入与部署不套用这套新规则；旧游戏可用“继续创作：保留玩法，增加手机手柄并保留完整触屏操作”重新生成。本轮不升级应用中心版本；要获得“短过期不正式暂停”的完整行为，须使用已区分 connected / input_active 的新固件。旧固件仍可触屏/手柄操作，但不能据此认为反复暂停问题已修复。

## 本地应用中心

入口：「应用 → 应用中心」；「我的创作」顶部也有发现入口与「上传作品」。遵循已确认的主设计稿：三个分栏、分类搜索、双列像素封面、详情页固定获取按钮；浏览中心不显示设备连接卡。封面是插画，不是设备截图。

- 离线预置六个真实 Lua 应用：坦克大战、飞机大战、午夜赛车、口袋像素宠、光点画板、一刻专注。不需要模型调用、互联网或额外外设；面向 480×480 屏幕和触摸。
- 点「获取 / 添加到我的创作」才保存独立副本。重复获取同一条目不重复创建；获取不会连接、部署或启动设备。随后在「我的创作」查看源码、确认运行，沿用已有 Works 校验、复用部署与先停再启链路。点「继续创作」可把源码交给手机 Agent 修改，修改才需要模型服务。
- 「上传作品」选择本地版本、填写名称（最多 24 字符且不超过 48 UTF-8 字节，约 16 个汉字）、介绍、分类，审查源码并确认有权分享及不含私密信息。仅生成本机不可变快照；同来源版本去重，后续修改不覆盖已上传条目。来源于预置的未修改副本保留玩法说明。
- 「我的上传」可查找自己的条目，详情中移除需确认。移除只影响中心记录，不删除我的创作或设备文件；预置条目不可移除。
- 目录仅在本机：用户快照写入应用私有 app-center.json，原子保存；预置源码来自 APK 内置资源。重启保留，卸载会删除本机记录。没有账号、跨设备共享、云端公开上传或同步，不展示虚构社区数据。
- 快照不复制对话意图、设备地址或模型配置，但 Lua 源码本身可能含私密内容；确认框和语法检查不等于隐私扫描或安全沙箱。读盘损坏会保留原文件并阻止空数据覆盖。

预置的顶部 PAUSE / PLAY 用于暂停与继续，EXIT 退出释放屏幕；游戏结束后可重开。坦克使用底部方向键和 FIRE；飞机拖动闪避、自动开火；赛车左右点击换道；宠物喂食/休息只保留本次会话；画板四色绘画、擦除和二次确认清空，退出不保存；专注提供 15/25/45 分钟与重置，仅屏幕到点提醒，无音频。

手动验收建议：获取坦克 → 查看源码并确认运行 → 获取飞机并切换运行 → 回到坦克验证已部署版本复用 → 上传任一本地版本 → 重复上传检查去重 → 移除中心条目并确认创作副本仍在。其余游戏的触摸、视觉、性能和长时稳定性也需实机验证。

## 生成输出与格式恢复

模型现在直接返回原始 Lua，不再将整段源码手工转义到 JSON 字符串中。格式为首行 -- MOSAICOBOT_APP_V1，接着两行 -- title: 中文标题、-- summary: 单行中文说明，随后完整 Lua，末行 -- MOSAICOBOT_END。传输头尾不写入源码；本地存储的 JSON 由 App 序列化，已有作品和部署包格式不变。

完整的单个 Lua/JSON 代码围栏、旧 JSON 应用包和拒绝回复仍兼容；不会猜测引号、补代码或静默选择多个应用中的一个。缺少结束标记（即使接口报告 stop）会触发有界续写，缺少外层代码围栏闭合也一样；完整包里的语法错误则进入完整修复。模型续写时改为重写新应用，会替换旧前缀，不把两份程序相拼。无进展的重复原始 Lua 前缀会转完整修复；整体仍受 8 次请求/12 分钟限制。

旧 JSON 包装损坏时改用原始 Lua 格式修复，错误提示区分包装损坏、缺少结束标记、重复应用和 Lua 校验失败，不回显模型原文。结束标记只证明传输边界，不能证明功能完整或运行正确；手机仍做原有语法与能力 lint。

## 联网数据与真实时钟

- 原“无法联网”拒绝来自手机生成协议和模块 lint，而非 Mosaico 没有 Wi-Fi。沿用固件现有 capability.call("http_request", ...) 和 json.decode，不虚构 http.get 接口，不需要新增固件模块。HTTP 能力返回的是 `HTTP <status>\n<body>` 文本，生成协议明确要求检查状态、拒绝截断响应并安全解析 JSON。
- 允许的生成格式限定为 HTTPS GET，8 秒请求超时参数、16 KiB 响应体和约 17 KiB 输出缓冲；禁止其他 capability 调用、下载写文件、自定义鉴权头或变更型请求。此格式检查仍是保守 lint，不是设备端安全隔离；不能保证恶意 Lua 不绕过。生成应用不获得手机模型 Key。
- 联网作品在上传前，以及已上传版本再次运行前，检查所需模块、已编译/配置启用的 HTTP 能力和设备域名白名单。只读取 `/api/config?fields=search_http_allowlist,enabled_cap_groups,enabled_lua_modules`，不读取模型 Key 或 Wi-Fi 密码。缺少模块或域名未授权时在写文件前停止，不自动放宽白名单。设备配置接口反映保存配置，运行时最终是否可用仍由固件调用结果决定。
- 运行确认弹窗显示源码声明域名，说明设备直接向第三方发送请求；第三方会收到请求参数和设备出口 IP。固件没有每应用的权限清单，不能将手机的确认或域名检查当作沙箱。
- 天气协议默认使用无需 Key 的 Open-Meteo 当前天气。未指定城市时生成显式城市选择器并注明默认城市，不猜测用户所在地。断网/失败显示不可用或标注过期的内存缓存，不伪造实时天气；天气刷新至少间隔 10 分钟，失败至少等待 60 秒。
- 时钟使用 system.time()/system.date()，按设备时区显示，未校时显示等待同步；system.millis() 只用于调度，不能当作真实时间。现有 HTTP 接口同步阻塞，等待请求时可能短暂停止时钟重绘和触摸；协议要求先提交加载画面，不声称无阻塞联网。

## 连接你的 Mosaico

- 默认开启「自动发现并连接」：App 启动、回到前台、局域网连接或地址变化时触发扫描；开关设置会保留。关闭自动发现后仍可手动扫描和连接。
- 扫描优先验证上次成功连接的地址，否则自动连接第一个通过接口校验的设备；其他设备保留在列表中，扫描结束后可切换。记住的是地址，不是经过认证的设备身份。
- 使用 mDNS（_esp-iris._tcp. / _http._tcp.）和私有 IPv4 探测。发现结果通过 Claw HTTP 80 端口的 /api/status 与 /api/lua-modules 复核；必须包含 display、delay、system 模块。手填地址可指定端口。
- IPv4 回退只扫描本机所在 /24 窗口或更小的实际子网，最多 254 个目标、12 个并发；单轮总预算 22 秒。mDNS 结果可覆盖当前实际私有子网的其他地址，但不扫描公网或跨路由网段。
- 网络变化会取消旧扫描并清除连接；恢复后自动扫描。退出前台停止扫描并清除连接状态，没有后台常驻服务或持续心跳。「已连接」表示最近一次接口验证成功，不保证设备随后始终在线。
- 设备请求绑定所选 Wi-Fi/以太网，不要求该网络能访问互联网；不改变模型请求的网络或代理配置。网络切换会取消正在进行的设备上传，不会自动重试。
- 找不到时先检查 Claw 已启动、Wi-Fi 一致及路由器的客户端隔离；可展开「找不到设备？手动输入地址」。仅支持当前私有 IPv4 子网，IPv6-only、跨网段或禁止局域网互访的网络不在本版保证范围。

扫描和自动连接只读设备接口，不会上传、发布或运行作品，也不等于安全配对。

## 原有 Claw 应用

「应用 → 设备应用」保留 11 个主屏入口和 3 个 Works 预装作品的源码目录映射，包括 Camera、CLAW、Works、Settings、IMU、Album、Music、Bricks、Weather、Interaction、Partner、Dino、Flappy Bird 与 Works Album。

该目录**不是当前设备的安装清单**。除 CLAW 独立对话入口外，目前不能从手机打开、停止或卸载这些系统应用；请在设备上操作。系统相册与 Works 相册是不同入口。生成作品使用独立 mb_ 前缀版本 ID，不覆盖或遮蔽系统预装包。

## 安全与连接边界

- Lua 校验是保守的 lint 和语法检查，**不是安全沙箱**；不能保证生成程序不会调用其他能力、死循环或耗尽资源。暂不自动执行，必须审查源码。正式自动运行前需固件实施能力隔离、内存/时间预算、取消和停止机制。
- Claw 现有 HTTP 文件接口无配对认证。自动发现和手动连接限定在当前局域网的 RFC1918 IPv4 地址，不扫描公网、不跟随重定向。HTTP 在可信局域网内仍可能被冒充；没有设备身份绑定前不能视为安全配对。仅在可信网络启用自动发现；连接后上传仍须明确确认。
- 模型请求强制 HTTPS，模型 Key 仅发给所配置模型服务，设备请求不带模型 Key。不要将模型地址改成不信任的服务。
- 为兼容 Claw 允许明文局域网 HTTP；这不是传输安全保证。后续需设备配对和请求认证。
- 已存在的版本目录仅在源码和清单摘要均一致时复用，拒绝覆盖。取消/断网可能留下一部分文件；文件缺失或不同会中止，不自动删除或覆写，请检查后再处理。
- 上传完源文件才写清单，然后显式 registry 发布；文件传输和发布不是同一个事务，不宣称原子部署。
- App 禁止云备份与设备迁移备份；生成版本保存在本应用私有目录，卸载会删除。
- 仅 debug 包可从私有 files/bootstrap.local.json 导入一次测试配置，随后立即删除；无导出接收器/配置 Provider。release 构建不会导入。日常使用推荐界面配置。
